# Prüfungen

Siehe measurements/browser-check.json und die zwei Benchmark-Rohberichte. npm test prüft Player/Builder und Release-Vertrag. npm run browser:test führt reale Chrome-/Chromium-Prüfungen gegen den gestarteten lokalen Server aus. Subjektive Hörabnahme, Firefox/Safari und Unity-Laufzeit bleiben offen. Der ausführliche Artikel-Prüfstand liegt im übergeordneten verification.md; alle ausführbaren Tests bleiben im Beispiel enthalten.
